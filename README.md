# Tiny Stack VM

[![rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/azkamahvin88/tiny-stack-vm/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/azkamahvin88/tiny-stack-vm/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

A compact interpreter for make.fun's tiny stack VM (ISA v1): 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input, output, and all ten traps with their exact exit codes.

Run: `node main.ts` (reads `/input`, writes `/output`).
